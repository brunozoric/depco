# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in the repository](https://github.com/changesets/changesets)

## Adding a changeset

Run `yarn changeset` to create a new changeset. This will prompt you to:

1. Select the type of change (major / minor / patch)
2. Write a summary of the change

The changeset is saved as a markdown file in this directory and committed with your PR.

## Versioning

Run `yarn changeset:version` to consume all changesets, bump the version in `package.json`, and update `CHANGELOG.md`.

## Publishing

Run `yarn changeset:publish` to publish the package to npm. This should be run after `yarn changeset:version` and a fresh build.
