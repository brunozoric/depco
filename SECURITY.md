# Security Policy

## Supported Versions

Only the latest release is supported with security updates.

## Reporting a Vulnerability

Please report vulnerabilities privately via [GitHub Security Advisories](../../security/advisories/new).

If you prefer email, contact [bruno.zoric@gmail.com](mailto:bruno.zoric@gmail.com) with the subject line "Security: dependency-upgrader".

**Do not report security vulnerabilities through public GitHub issues.**

## What to Include

- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Potential impact

## Response

You can expect an initial response within 72 hours. A fix or mitigation will be published as soon as possible depending on severity.
