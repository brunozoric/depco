# Support

## Bug Reports

Open a [GitHub issue](../../issues) with steps to reproduce, expected behavior, and actual behavior.

## Questions

For usage questions, open a [GitHub discussion](../../discussions) or an issue tagged `question`.

## Feature Requests

Custom feature development is available as a paid service. Contact [bruno.zoric@gmail.com](mailto:bruno.zoric@gmail.com) to discuss requirements and pricing.

## Security Vulnerabilities

If you discover a security vulnerability, please report it privately via [GitHub Security Advisories](../../security/advisories/new) instead of opening a public issue.
